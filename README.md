# The Leadership Library

*Books that shape how I think. Lessons that shape how I lead.*

Live at **[mutaafaziz.com/library](https://mutaafaziz.com/library/)**: nine books on engineering
leadership, each with a labelled summary of its argument, and my own interpretation,
applications, critique, experiments and dated reflections as I write them.

- **Everywhere:** the same app pattern as [Hearth](https://mutaafaziz.com/hearth/) and
  COLD GAS. A frosted nav, an [aurora-field](https://github.com/mutaaf/aurora-field) sky
  that assembles into a shelf, an open book and a balance, then the shelf.
- **On the iPhone Duo:** it becomes a book. Closed, you hold one page. Open, the hinge is
  the gutter of a two-page spread, with the shelf on the left and the book on the right.
  Unfold mid-chapter and the shelf swings open from the hinge while you keep your place.

## Run it

```sh
npm install
npm run build          # content/ → dist/library/
npm run preview        # http://127.0.0.1:4391/library/
npm test               # schema, draft-leak and sanitizer tests
npm run e2e            # Playwright, WebKit + Chromium
npm run stack          # production locally: the site at / and the library at /library/
                       # (needs ../mutaafaziz-site; http://127.0.0.1:8790/)
```

Add `?duo=open`, `?duo=closed` or `?duo=auto` to any URL to see the book form on a desktop.
`auto` follows the window size, so resizing the window unfolds and folds it. `?duo=off`
turns it off again for the tab.

## Write in it

See **[docs/CONTENT.md](docs/CONTENT.md)**. In short: every block says whose claim it is
(*Book's argument*, *My interpretation*, *My application*, *My critique*), and nothing
is public until its `visibility` is `published`. Edit, open a PR, merge: it deploys.

**Add a book from your phone:** [open the Add a book form](https://github.com/mutaaf/library/issues/new?template=add-book.yml),
type a title, ISBN or link, submit. A few minutes later the issue gets a reply with the
live link. Comment `/remove` on it to take the book back out. From a laptop:
`npm run add -- "Thinking in Systems"`, then commit.

## How it's built

See **[docs/DESIGN.md](docs/DESIGN.md)** and **[AGENTS.md](AGENTS.md)**. It's static HTML
generated by a zero-dependency Node script, with no framework, no database and no
tracking. It's served by Cloudflare Workers static assets on the route
`mutaafaziz.com/library*`.
